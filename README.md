# Curso Git y GitHub

## Descripción
Este repositorio fue creado como parte de la actividad del curso Git y GitHub, con el propósito de aprender a utilizar el control de versiones y conocer las herramientas que nos permiten organizar y compartir proyectos.

## ¿Qué aprendí?
Aprendí qué es Git, qué es GitHub, cómo crear un repositorio y para qué sirven los commits. También conocí la importancia de README para explicar el contenido de un proyecto.

## Comandos de Git
- `git init`: inicializa un repositorio.
- `git status`: muestra el estado de los archivos.
- `git add`: prepara archivos para guardar los cambios.
- `git commit`: registra los cambios.
- `git push`: sube los cambios a GitHub.
- `git pull`: descarga los cambios del repositorio remoto.

## Objetivo
Practicar el uso de Git y GitHub para organizar proyectos, guardar cambios y compartir archivos.
